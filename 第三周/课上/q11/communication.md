# Issue：空白姓名被当作有效输入

环境：Windows（版本待确认）；Shell、Python、greetlab 版本：待确认。

复现步骤：

1. 运行 `sdt-greet --name " "`。
2. 检查输出和退出状态。

期望：不输出问候语，以状态码 2 退出。

实际：输出 `Hello,   !`，以状态码 0 退出。

# 提交信息

标题：`拒绝空白姓名参数输入`

正文：`--name` 原先接受空白字符串，使无效问候语仍以成功状态结束。解析参数后检查 `name.strip()`，结果为空时抛出 `SystemExit(2)`。

# 评审意见

**Blocking：** `main()` 解析参数后直接输出，空白姓名会被当作成功请求，调用脚本可能误判。请在 `print` 前拒绝空白输入，以状态码 2 退出并保留对应测试。
